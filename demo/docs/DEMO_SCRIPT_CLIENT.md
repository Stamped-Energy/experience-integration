# Five-minute plant visitor path

Use View as **Plant head** unless noted.

1. **Quality · Agent at work** (`/quality/agent`) — status strip, Working on now, Waiting on you. Point at the authority line.
2. Open one **Waiting on you** decision → Inbox or link confirmation.
3. **Lots · Control and capability** (`/quality/spc`) — summary strip, Cpk vs target, one chart with a signal.
4. **Open lot** from the signal (or Lots at risk) → lot detail risk word.
5. Switch View as to **Stamped engineer**.
6. **Process · Engineering · Simulation campaigns** (`/process/simulations`) — show the console stays behind Engineering.
