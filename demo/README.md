# Stamped product UI (showcase)

The Stamped product on a fictional demonstration plant with illustrative data. No API or database. Deployed as showcase.stamped.work (Vercel project `demo-stamped`, root `demo`).

Read [FOUNDATION.md](FOUNDATION.md) before building: tokens, components, data module and route conventions.

```bash
pnpm install
pnpm dev     # http://localhost:3010
pnpm lint && pnpm test && pnpm build
```
